# AI Email Threat Analyser (Prototype)

A simple web application for analysing email files and identifying potential security threats.

The application accepts `.eml` files and analyses the email to provide a security assessment.

## Live Demo

https://arleta653.pythonanywhere.com/

## Features

- Upload `.eml` email files
- Analyse email content and headers
- Detect potential email threats
- AI-based analysis
- Simple and clean web interface
- Light and dark mode
- Detailed analysis report

## Tech Stack

- Python
- Flask
- HTML
- CSS
- JavaScript
- Google Gemini API
